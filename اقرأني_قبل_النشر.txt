رحلتي — نسخة محسّنة للنشر كتطبيق ويب تقدمي (PWA)
====================================================

الملفات:
- index.html: التطبيق، مع زر تثبيت/إرشادات تثبيت.
- manifest.json: بيانات الاسم والأيقونات وطريقة العرض.
- sw.js: التخزين المؤقت ودعم فتح التطبيق عند انقطاع الاتصال بعد الزيارة الأولى.
- icon-192.png و icon-512.png: أيقونات التطبيق.
- .nojekyll: يساعد على نشر الملفات الثابتة عبر GitHub Pages.

النشر المجاني المقترح عبر GitHub Pages:
1. سجّل الدخول إلى GitHub وأنشئ مستودعًا جديدًا (Repository).
2. ارفع محتويات هذا المجلد إلى جذر المستودع، وليس ملف ZIP نفسه.
3. افتح Settings ثم Pages.
4. ضمن Build and deployment اختر Deploy from a branch، ثم الفرع main والمجلد /(root)، واضغط Save.
5. انتظر حتى يظهر رابط HTTPS في صفحة Pages.
6. افتح الرابط على الهاتف. على Android استخدم Chrome، وعلى iPhone/iPad استخدم Safari ثم مشاركة > إضافة إلى الشاشة الرئيسية.

ملاحظات مهمة:
- لا يمكن تثبيت التطبيق مباشرة من ملف ZIP أو من file://؛ يلزم رابط HTTPS.
- البيانات محفوظة محليًا في المتصفح على الجهاز نفسه، ولا توجد حاليًا حسابات أو مزامنة سحابية بين الأجهزة.
- احتفظ بنسخ احتياطية من داخل صفحة «السجل والنسخ الاحتياطي» قبل تغيير الجهاز أو مسح بيانات المتصفح.
- العمل دون اتصال يتطلب زيارة ناجحة أولى لتحميل الملفات وتفعيل Service Worker.
- اختبر التطبيق بعد النشر على جهازك قبل الاعتماد عليه. هذه الحزمة لم تُنشر إلى الإنترنت بعد.
